# 漢字のよるめいろ

漢字の形をした夜の3D迷路を歩き、どの漢字かを当てるゲームです。小学1年生の全80字と、小学2年生の夏休みまでの71字、合わせて151字で遊べます。インターネット接続やインストールは必要ありません。

## Macで起動する

1. Macで「ターミナル」を開きます。
2. ターミナルで、このフォルダへ移動します。たとえばフォルダが「ダウンロード」にある場合は、次のように入力します。

   ```sh
   cd ~/Downloads/kanji-maze
   ```

3. 次の行を入力して、ゲーム用のサーバーを起動します。

   ```sh
   python3 dev-server.py
   ```

4. MacのSafariやChromeで [http://localhost:8642](http://localhost:8642) を開きます。
5. 終わるときは、ターミナルを選んで `control` キーを押しながら `C` キーを押します。

画面を直接ダブルクリックして開くのではなく、上のサーバーから開いてください。

## 同じWi-FiのiPadから開く

1. MacとiPadを同じWi-Fiにつなぎ、Macで上のサーバーを起動しておきます。
2. Macの「システム設定」→「Wi-Fi」→接続中のWi-Fiの「詳細」を開き、「IPアドレス」を確認します。`192.168.1.23` のような数字です。
3. iPadのSafariで、`http://MacのIPアドレス:8642` を開きます。IPアドレスが `192.168.1.23` なら、`http://192.168.1.23:8642` です。
4. Macに通信を許可する確認が出たら「許可」を選びます。

開けない場合は、両方が同じWi-Fiか、Macがスリープしていないか、ターミナルのサーバーが動いたままかを確認してください。学校や公共施設のWi-Fiでは、機器どうしの通信が止められていることがあります。

## 遊び方

1. 「がくねん」「いつまで」「ちず」「ほっきょくせい」を選び、「スタート」を押します。2年生では1年生の漢字もすべて出ます。
2. 初めて遊ぶときは操作の説明が出ます。「わかった」で閉じます。あとから設定画面の「そうさの せつめい」で何度でも見られます。
3. 夜の迷路を歩き、道の曲がり方、交差点、行き止まりから漢字を想像します。
4. 分かったら、いつでも「こたえる」を押して4つから選びます。
5. 正解すると空へ上がり、迷路の漢字、読み、意味、得点が見えます。「つぎの かんじ」で続けられます。

少ない道だけを歩いて正解するほど高得点です。間違えると300点下がります。「ちず なし」では得点が1.5倍になります。

### iPad・iPhoneの操作

- 画面の左半分を指で押し、そのまま動かすと歩きます。
- 画面の右半分を指でなぞると、見回せます。
- 地図を「あり」にすると、右上の半紙に歩いた道だけが墨で描かれます。赤い印が現在地と向きです。

### Macの操作

- `W` / `↑`: 前へ歩く
- `S` / `↓`: 後ろへ歩く
- `A` / `←`: 左へ歩く
- `D` / `→`: 右へ歩く
- 迷路の画面をマウスでドラッグ: 見回す

## 開発者向け確認

迷路生成と得点計算の検査は、リポジトリ直下で次を実行します。

```sh
node tools/build-kanji-data.mjs
node test/maze-gen.test.mjs
```

`tools/build-kanji-data.mjs` は、同梱した KanjiVG と `data/curriculum.json` から151字のゲーム用データを作ります。ゲーム中に SVG やネットワークを読み込むことはありません。
