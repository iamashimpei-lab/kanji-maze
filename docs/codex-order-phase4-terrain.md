## 実装の指針

### とめ・はね・はらい

- KanjiVG の各 `<path>` には `kvg:type` 属性(㇐ ㇑ ㇒ ㇏ ㇚ など)がある。これを build 時に抽出し、末端の終わり方を tome / hane / harai に分類する対応表を作る(代表例: ㇒ ㇏ ㇙ 系 = はらい、㇚ ㇛ ㇃ ㇉ 等のフック付き = はね、㇐ ㇑ 等 = とめ。実データの type 分布を見て表を埋め、判断に迷った type は acceptance packet に一覧で出す)
- 生成データの各画に `ending: "tome"|"hane"|"harai"` を追加
- 高さは「画の末端からの距離」の関数として maze 層で計算(floorHeightAt)。カメラ y = EYE_HEIGHT + floorHeightAt。床の見た目は、末端部分だけ傾斜メッシュを重ねる(全床の高さメッシュ化はしない。平面床 + 末端パッチで十分)
- はね の先端は反り上がった「くちびる」状の小さな壁で終わる(飛び越せなくてよい、見た目)
- はらい は半径テーパーで壁の彫り込み自体がすぼまる(マーチングスクエアの距離場を、末端距離に応じた可変半径に拡張)

### 意味の世界観

- 新データファイル(例 `tools/kanji-themes.mjs` → 生成データに theme を焼き込む)に 151 字ぶんのカテゴリを手書きする。明確に分類できる字だけ具体カテゴリ、迷ったら neutral(それが「うっすら」を守る)
- 表現の目安(カテゴリごとに 2 要素まで):
  - water: 床色をわずかに青緑へ + 通路に沿う細い光の帯(ゆらゆらは shader 不要、透明度の低い帯で可)
  - mountain: 壁色をわずかに茶灰へ + 低ポリの岩を壁際に instanced で数個
  - plant: 床にわずかな緑味 + 草の房(板ポリ交差)を疎らに
  - fire: 暖色の点光源 1〜2 個 + 床に炭色の斑
  - sky: 星を少し増やす + 空の色をわずかに変える
  - neutral: 現行のまま
- 種明かし画面・minimap には持ち込まない(迷路内だけの気配)
