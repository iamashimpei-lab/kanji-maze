# 発注書: 第 3 弾補遺 — タッチ操作の全面変更(タップで歩く / 2 本指で向く)

## 1. 目的・変更対象・スコープ外

- **目的**: 晋平さん指定の新タッチ操作へ置き換える(現行の仮想スティック + 右半分ドラッグは子どもに伝わらなかった)
  1. **1 本指で画面を押す**: 押した画面位置の方向へキャラがなめらかに向き直り、押している間そちらへ歩き続ける。指を動かせば追従。離すと停止
  2. **2 本指で横になぞる**: 移動せず、なぞった方向へ視点が回る
  3. **2 本指で縦になぞる**: 上下を見る(北極星の確認用。1 本指では pitch を変えない)
- **変更対象**: `src/controls.js`(全面改修可)、`src/main.js` の入力消費部、`index.html` / `src/ui.js` / `style.css` の操作ガイドと仮想スティック DOM の削除
- **スコープ外**: PC 操作(WASD/矢印 + マウスドラッグ)は現状維持。壁描画・迷路ロジック・得点・設定・種明かしには触らない

## 2. 制約

- 静的サイト・ビルドなし・three.js は vendor 固定・npm 導入禁止(従来どおり)
- 「こたえる」ボタン等の HUD 上のタッチが移動として誤発火しないこと(canvas に届いた pointer イベントだけを移動に使う)
- Safari のダブルタップ拡大・スクロール等のジェスチャを canvas 上で抑止する(touch-action / preventDefault)。ページ全体のピンチ拡大は殺しすぎない
- 酔い防止のため、タップによる向き直りの旋回速度に上限を設ける(毎秒 150 度程度、要調整コメント付き)

## 3. 関連 incident・同型事故

## 実装の指針(拘束ではない)

- タッチ位置 → 方向: 画面 x の中央からのずれを水平角へ変換(カメラの視野角に比例)。タッチ中は目標 yaw へ every-frame で近づける(旋回速度上限つき)。前進は「現在の向き」でなく「目標へ旋回しながらの前進」で自然に曲がる挙動にする
- 2 本指: pointer を 2 つ捕捉したら移動を止め、2 点の中点の移動量で yaw / pitch を回す(現行ドラッグの感度を流用)
- ガイド文言(タッチ版) 例: 「いきたい ほうを ゆびで おしつづけると あるくよ」「2ほんの ゆびで よこに なぞると むきが かわるよ」「うえを みたいときは 2ほんの ゆびで たてに なぞってね」
- PC 判定は現行の切り替えロジックを流用
