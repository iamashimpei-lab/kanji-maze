# 漢字迷路ゲーム 企画メモ（正本）

作成: 2026-08-09。晋平さんとの企画会話で確定した内容だけを記録する。

## コンセプト

漢字の形をした 3D 迷路（壁に囲まれた通路）を一人称視点で歩き回り、地形の手がかりから「これは何の漢字か」を推理して当てる学習ゲーム。iPad / iPhone で遊べることが前提。

## 確定した仕様

### 迷路の構造

- 迷路の平面図 = 漢字の形そのもの。漢字全体が一つの繋がった迷路であり、画を順番にたどる一筆書き方式ではない
- 画（線）= 太い道。離れたパーツの間をつなぐ通路 = 細い道（吊り橋・トンネルなど、見た目ではっきり区別する）
- スタート地点 = 一画目の書き始めの端
- 歩く順番は自由。書き順は強制しない（書き順は正解後の画面で見せる）
- 3D 一人称視点。迷路の中にいる限り全体像は見えない（これ自体が目隠しの役割を果たす）
- 交差点（十の中心など）、輪っか（口・日・田）、行き止まりの数と配置が、そのまま推理の手がかりになる

### 出題範囲の選択

- 対象は小学校 1〜6 年の配当漢字 1026 字（1年80 / 2年160 / 3年200 / 4年202 / 5年193 / 6年191。2020年度全面実施の現行学習指導要領）
- プレイ前に「学年」と「何月まで」を選ぶ
  - 学年ごとの漢字の範囲 = 国の学年別漢字配当表で決まる（公的・固定）
  - 月ごとの順序 = 国の基準には存在しない。教科書会社の掲載順で決まるため、光村図書の年間指導計画 + 新出漢字順をデータ化して使う（第 2 段階）
- 月は手動選択とする。補習校など進度のずれを吸収するため、誕生日等からの自動計算はしない

### 手がかりと難易度

- 北極星: 空の北側に常に見える。漢字がどちらを向いているかの手がかり
  - 低学年: 迷路は常に正位置 + 北極星表示
  - 中級: 迷路が回転した状態で出題 + 北極星で上が分かる
  - 上級: 北極星なし、または時々雲に隠れる
- 回転出題は「すでに習った範囲の復習」に限定する。未習の漢字を回転で見せない
- 正解後の画面では必ず正しい向きの漢字を大きく表示する
- 地図: 通った道が墨で描かれる半紙風の地図。**プレイ前の設定でオン/オフを選択制にする**。オフを選ぶと得点が上乗せされる（挑戦の位置づけ）

### 得点

- いつでも回答できる。踏破率が低いうちに当てるほど高得点（賭けの緊張感が核）
- 誤答はペナルティ
- 地図なし選択はボーナス倍率

### 正解演出（最重要のご褒美）

- 正解の瞬間、カメラが空へ昇る
- 歩いた軌跡が墨の筆跡として光り、迷路全体が漢字として浮かび上がる
- 読み・意味を表示して締める

### 採用済み・後段階で実装する要素

- とめ・はね・はらいの地形化: はね = 先が反り上がるジャンプ台 / はらい = だんだんすぼまる下り坂 / とめ = 壁でぴたっと終わる
- 漢字の意味を世界観にうっすら混ぜる（川 = 床に水が流れる / 山 = 岩肌と上り坂 / 森 = 壁に木々）。気づける子だけが気づく隠しヒント
- 解いた漢字が拠点の村に建物・住人として増えていく（図鑑を兼ねる収集要素。全 1026 字が集める対象）

### 不採用

- 案内人モード（一人が歩き、一人が地図で誘導する二人組モード）
- 書き順どおりの一方通行（自由探索の核と両立しないため撤回済み）

### 候補（未確定・晋平さん未裁定）

- 似た漢字の罠（大・犬・太 など。入れるなら上級のみ）
- 読みのかけら（道中で拾えるヒント。拾うと減点）

## 段階計画

- **第 1 段階（MVP）**: 1 年生の漢字 10 字でコアの一周（探索 → 回答 → 空からの種明かし）を成立させる。仕様 = `docs/codex-order-mvp.md`
- **第 2 段階**: KanjiVG（漢字の画形状の公開データ）からの迷路自動生成で 1026 字対応、光村図書ベースの月別データ、回転出題
- **第 3 段階**: とめはねはらい地形、意味の世界観、村、演出強化

## 技術方針

- まずはブラウザ版（静的サイト + three.js）。iPad の Safari で開いてそのまま遊べる形
- App Store 向けのネイティブアプリ化は遊びが固まってから検討
