## 実装の指針

### 記録

- 正解時に `{char, count, firstSolvedAt}` を保存。図鑑・村はこの集合から描く

### 図鑑(ずかん)

- スタート画面に「ずかん」ボタン。学年タブ(1〜6 年。未対応学年は準備中表示)で配当字を一覧
- 解いた字 = 半紙に墨の字 + 読み + 意味 + 正解回数。未解答 = 字を薄い灰色で表示し、読みと意味は伏せる
- 進捗表示「1ねんせい 80 じちゅう 43 じ」

### 村(むら)

- スタート画面に「むら」ボタン。canvas 1 枚に夜の村の全景
- 解いた字のテーマ(第 4 便で導入した theme を再利用)ごとに村の要素が増える: water → 小川や池 / plant → 木や畑 / mountain → 遠景の山 / fire → かがり火 / neutral → 家や灯篭。おおよそ「字 1 つ = 要素 1 つ」で、多くなったら密度を上げる
- 新しい要素が増えた直後の正解画面に「むらに 〇〇が ふえたよ」の一言を出す
- 村の絵の中に対応する漢字は書かない(あくまで風景。タップした要素の由来の字を小さく出すのは可)
