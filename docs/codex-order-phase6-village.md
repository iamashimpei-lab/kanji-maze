## 1.5 回答方法の仕様

- 「じぶんで にゅうりょく」= 回答パネルに 1 文字の入力欄 + 「こたえる」ボタン。IME で漢字を入力(読みを打って変換する行為自体が学習)。前後の空白は無視、正解字と完全一致で正解
- 誤答時の扱いは 4 択と同じ(-300、「おしい！」表示、探索に戻る)。入力欄は誤答後クリア
- 入力モードの合計得点は 1.5 倍(score.js に倍率追加。地図なし倍率とは乗算で重なってよい)。結果画面の内訳に「じぶんで にゅうりょく ×1.5」の行を出す
- 設定は保存対象。iPad ではフォーカス時に IME が開くので、回答パネルを画面上半分に寄せてキーボードと重ならないようにする
- テスト: 得点倍率のロジックを node テストに追加

## 1.6 全字テーマ化の仕様(可愛さの土台)

- `tools/kanji-themes.mjs` の対応表を全 1026 字に拡張する。カテゴリは既存 7 種を再編して 9 種: `water`(水・天気の雨雪) / `mountain`(山・石・地形) / `plant`(草木・田畑・実り) / `fire`(火・熱・光の赤系) / `sky`(空・星・天体・昼夜) / `animal`(どうぶつ・虫・魚・鳥) / `life`(ひと・からだ・家族) / `town`(まち・たてもの・のりもの・どうぐ) / `neutral`(かず・こころ・ことば等の抽象概念のみ)
- 割当は 1 字ずつ意味に基づいて対応表に書く(機械的な推測で埋めない)。判断に迷う字は neutral でよいが、**neutral は全体の 35% 以下**が合格ライン。生成スクリプトはテーマ分布を PASS 行で出力する
- **意味バレ対策(重要)**: 現行コードの「答えにならないよう neutral に絞る」方針は廃止し、代わりに **4 択の誤答候補 3 字を正解と同じテーマから優先的に選ぶ**(`src/main.js` の openAnswers)。出題プール内に同テーマが 3 字未満のときだけ他テーマで補う。これで雰囲気は「ヒント」に留まり「答え」にならない。この選定ロジックは純関数で export し node テストする(同テーマ十分時は全候補同テーマ / 不足時の補充 / 4 字ユニーク)
- `src/render3d.js` の THEME_STYLE に 9 テーマ分の配色(床・壁・背景・霧)を定義。加えて安い夜の演出を最低 3 テーマに入れる(例: plant = 蛍の光点がゆっくり漂う / fire = 暖色のちらつく光点 / sky = 星を倍増 + 流れ星。いずれも点群 + 色替えで、新しいジオメトリ生成や画像は使わない)。演出はプレイの視界を妨げない控えめな量にする

## 実装の指針

### 記録

- 正解時に `{char, count, firstSolvedAt}` を保存。図鑑・村はこの集合から描く

### 図鑑(ずかん)

- スタート画面に「ずかん」ボタン。学年タブ(1〜6 年)で配当字を一覧
- 解いた字 = **カード風**に表示: テーマ色の枠 + 半紙の地 + 墨の字 + 読み + 意味 + 星(正解 1 回 = 星 1、3 回 = 星 2、5 回 = 星 3)。未解答 = 字を薄い灰色で表示し、読みと意味は伏せる
- はじめて解けた字は正解画面に「あたらしく ずかんに のったよ」を出し、図鑑側でもカードがほんのり光る
- 進捗表示「1ねんせい 80 じちゅう 43 じ」

### 村(むら)

- スタート画面に「むら」ボタン。canvas 1 枚に夜の村の全景
- 解いた字のテーマ(1.6 の 9 カテゴリ)ごとに村の要素が増える: water → 小川や池 / plant → 木や畑 / mountain → 遠景の山 / fire → かがり火 / sky → 空の星や月が豊かに / town → 家・橋・灯篭 / neutral → 石畳や道標。おおよそ「字 1 つ = 要素 1 つ」で、多くなったら密度を上げる
- **村の住人「よるのせいれい」(可愛さの中核)**: animal / life の字を解くと、小さな光の生き物(丸い体 + 耳や尻尾程度のシルエット、2〜4 パターン)が村に住み着き、ゆっくり漂って動く。クリック / タップすると吹き出しで由来の字と読みが出る(復習の入口)
- 新しい要素・住人が増えた直後の正解画面に「むらに 〇〇が ふえたよ」の一言を出す
- 村の絵の中に対応する漢字は書かない(あくまで風景。タップした要素の由来の字を小さく出すのは可)
