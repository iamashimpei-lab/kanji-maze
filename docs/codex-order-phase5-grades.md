## 実装の指針

### データ

- curriculum.json(1〜2年)+ curriculum-upper.json(3〜6年)を統合して読む。単元は month の学校年度順(4→3月)に並べる
- 5年の「永」は補遺として 3 月に配置済み(そのまま扱う)

### 読み・意味

- `tools/readings.mjs` は「1〜2年の手書き辞書(既存)」+「3〜6年の意味手書き辞書(新規)」+「official-readings.json からの読み自動決定」の 3 層に再構成してよい
- 意味の執筆は学年ごとにファイル分割可(`tools/meanings-grade3.mjs` 等)。会話調にせず名詞的な一言で統一

### 回転出題

- 設定に「まわす: しない / まわす(むずかしい)」を追加。既定 = しない。保存対象
- ラウンド開始時に 30°〜330° の一様乱数で回転角を決め、正規化座標を中心 (0.5, 0.5) 回りに回転してから迷路生成に渡す
- 北極星・星空は世界固定のまま(= 回転の基準になる)。minimap は回転後の世界をそのまま描く(それが手がかりの一部)
- 正解演出の墨は回転後の姿で見せてよいが、結果カードの大きな字は必ず正位置
- 4 択の誤答候補・得点は従来どおり

### 設定画面

- 学年 1〜6 を全て有効化。「いつまで」は学年のデータに存在する月だけを学校年度順に出す(1年 = 9月〜3月、他学年 = 4月〜3月)。最後の月に「(ぜんぶ)」を付記
- 学年 g を選ぶと g-1 までの全字 + g の選択月まで、の累積(現行 2 年の仕様を一般化)。注記「まえの がくねんの かんじも でるよ」は 2 年生以上で表示

acceptance packet: 結論 / 変更ファイル / oracle (a)(b) 生出力 / 生成データのサイズと対策 / 意味執筆の自己再走査の結果(直した字があれば一覧) / 未解決事項
