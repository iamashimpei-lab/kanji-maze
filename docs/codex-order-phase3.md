## 詳細仕様

### 通路モデルの全面変更(グリッド → 距離場)

いまの「グリッドセルの集合」をやめ、**「画の折れ線から半径 r 以内 = 歩ける」**という連続モデルにする。

- **世界スケール**: 正規化座標 0..1 を一辺 W メートルへ。画数で W を選ぶ: 1〜4画 = 64 / 5〜8画 = 80 / 9〜12画 = 96 / 13画以上 = 112(現行の size×2m より約 1.4〜1.5 倍大きい)
- **通路半径**: 画 = r_stroke 1.7m(幅 3.4m。現行 2m 幅の 1.7 倍)。橋(離れたパーツの接続) = r_bridge 0.95m。橋には現行同様の柵を沿わせ、床色も変えて「細い道」の見た目を保つ
- **橋の算出**: 画の集合ごとの連結成分を求め、成分間の最近接点対を結ぶ直線セグメントを橋にする(単一連結になるまで)。「視覚的には接しているが座標がわずかに離れる」対策として、成分間距離が 2.4m 以下なら橋でなく r_stroke の通路として直結する(第2弾のスナップと同じ意図)
- **衝突判定**: プレイヤー中心から全セグメント(画 + 橋)への最短距離を取り、`min(dist_stroke) ≤ r_stroke - 0.45` または `min(dist_bridge) ≤ r_bridge - 0.45` なら立てる。セグメント数は最大でも千程度なので毎フレーム総当たりで足りるが、必要なら粗い空間ハッシュを入れてよい
- **踏破率**: 全画の折れ線に沿って約 1.2m 間隔でサンプル点を打ち、プレイヤーが r_stroke + 0.5m 以内を通ったら訪問済み。踏破率 = 訪問済み ÷ 全サンプル。連結性テストもこのサンプル点で行う(同じ画の隣接サンプルは連結、異なる画のサンプル対は距離 ≤ 2×r_stroke で連結、橋の両端も連結、として union-find で 1 成分になること)

### 壁と床の描画(滑らかさの本体)

- 歩行可能領域(カプセルの合併)の輪郭を**マーチングスクエア**で抽出する。サンプリング解像度は一辺 220〜300 程度(スケールに応じて)。得られた輪郭を Chaikin 平滑化 2 回でなめらかにする
- **壁**: 外周の大きな矩形(世界より一回り大きい)を THREE.Shape とし、通路輪郭を hole として与えて ExtrudeGeometry(高さ 2.6m、bevel なし)で 1 メッシュに。material は現行の壁色系 + transparent(種明かしのフェードで使用中)
- **床**: 世界全体に 1 枚の平面(通路色)。橋の部分だけ橋色の細い帯メッシュを橋セグメントに沿って敷く
- 視点の高さ 1.5m・霧・星空・北極星は現行のまま
- **種明かしの墨**: グリッドの箱を並べる方式をやめ、訪問済みサンプル区間の折れ線を「太い筆線」(THREE.MeshBasicMaterial の帯メッシュ、round cap 相当の円ジオメトリを継ぎ目に置く)で描く。未訪問区間は薄い色の同じ帯。カメラ上昇・霧拡張・壁フェードは現行踏襲
- **minimap**: canvas 2D の lineWidth を通路幅相当にし、lineCap/lineJoin = "round" で訪問済み区間だけ墨色で描く(いまの点描よりも筆らしくなる)

### スタート位置・向き

- スタート = 1 画目の最初のサンプル点。開始向き = 1 画目の進行方向(現行 initialYaw の意図を維持)
- 移動速度は 3.15 → 3.8 m/s に微増(世界が広がるため)。視点回転感度は現行のまま

### 操作ガイド(初回オーバーレイ)

- スタート後、迷路画面の上に半透明の説明を重ねる: 左半分に「ここに ゆびを おいて あるく」+ スティックの絵、右半分に「ここを なぞって むきを かえる」+ 矢印の絵。下に「わかった」ボタン
- タッチ非対応環境(パソコン)では文言を「WASD・やじるしキーで あるく / マウスを おしながら うごかして みまわす」に切り替える
- 「わかった」で閉じ、localStorage の保存(`kanji-maze-save-v1` に guideDone フラグ)で次回以降は出さない。設定画面に小さな「そうさの せつめい」リンクを置き、いつでも再表示できるようにする

### 整理

- グリッド前提のコード(cellKey / worldToCell 等)で不要になるものは削除してよい。ただし `generateMaze` 相当の純ロジック(セグメント構築・橋・サンプル点・連結性)は DOM / three.js 非依存のモジュールに保ち、node テスト可能にする
- `data/curriculum.json` `tools/readings.mjs` `src/kanji-data.generated.js` はそのまま使う(再生成不要。ただしビルドスクリプトが新モデルの前処理を持つなら (b) の検算は保持)
